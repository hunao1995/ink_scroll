# 「墨卷 · Ink Scroll」策展评审

评审人：新媒体/互动装置策展视角 · 2026-10-29 · 只读仓库 `ink_scroll`（最后提交 b0f609f）
依据：README、docs/ABOUT · FORMS · ART-SURVEY · ETHICS；本机镜像用 Playwright 实开 20 余次（截图在 `reviews/shots/`）。
标注规则：凡未在文件或页面里亲眼看到的，一律标「未核实」；不编造外部作品名与年份。

## 1 · 作为作品的评价 —— 5 / 10

**概念成立，但只成立一句话。** "一幅被墨盖住的画，光落在哪里哪里显色" 是一条干净、一眼可读、无需展签的规则，这是它最好的资产。
问题是这条规则之下没有第二层：墨为什么盖住画？光是谁的光？作品自己的文档（FORMS.md §1）已经承认 "42 种输入 × 1 种形式 = 同一件作品换了 42 层皮"，我同意这个自我诊断。

**留白与隐喻不自洽的三处（页面所见）**
- "墨"其实是 Sobel 边缘线稿（`04-scene0-reveal.png`）：黑色粗轮廓压在米白纸上，读起来是白描/填色本，不是水墨的"晕"。真正像"光"的反而是 **暗调** 风格（`19-style-dark.png`），但它放弃了纸的美学。
- 被揭示的"画"是 AI 生成图（README 自述）：竹林里有熊猫（`05-scene1.png`）、花鸟是麻雀加大山雀。隐藏层是这件作品唯一的秘密，秘密本身却是提示词产物，观众揭开后得到的是"预期中的东西"。
- 第 6、7 张（程序化视差、点云，`05-scene5/6.png`）与前 5 张不在同一个隐喻里：点云里的光圈是黑洞而不是光。立轴 + 点云 + 红蓝立体是三件作品，不是一件。
- 分享卡（`15-share-card.png`）的印章就是一个字"印"，题款"一起点亮一幅画"；没有作者、没有日期。印章是水墨里"作者在场"的位置，这里是空的。

**11 种形式的实际落差**：我逐个用 URL 打开过。延迟 / 供奉 / 驱赶 / 召唤 / 书写在截图里几乎与默认"照亮"不可区分（`11-form-*.png`），驱赶只多出一抹淡痕；共处是一行文字"这幅画要两个人一起才揭得开"加全黑屏；仪式按三下后仍未开启（未核实是否因脚本点击方式）。形式在状态机里存在（`S.form` 确实切换），在观众眼睛里不存在。

**与三件参照作品的位置关系**（依据 docs/ART-SURVEY、FORMS 及公开资料）
- Lozano-Hemmer《Pulse Room》：输入是**非自愿**的身体信号（心跳），后果是**物理且有记忆**的（灯泡队列被推走）。墨卷的输入是自愿的指点，后果可逆、不出屏幕、不过夜。"供奉/累积"是朝这个方向迈的半步，但仍是单次会话。
- Random International《Rain Room》：环境**回应你但不服从你**。墨卷的光完全服从（它就是光标）。"延迟 8 秒"和"驱赶"是它目前最接近"不服从"的两处，也是最值得放大的两处。
- teamLab：尺度、无边界、身体进入画面。墨卷在手法上最接近 teamLab 的屏幕类作品（触碰即生花），但没有尺度，又用了 AI 图，很容易被读成"小号 teamLab"。它要脱身，靠的不是再加传感器，而是上面两位的东西：记忆与不服从。

打分理由：概念 8、隐藏层内容 3、形式可感知度 4、作者在场 2、工程诚实（ETHICS、失败回落、零采集）8 → 综合 5。

## 2 · 展厅可行性 —— 60 ㎡ 明天进场，缺什么

当前状态：一个网页 + 一台能跑 Chrome 的机器。能亮，不能"展"。必须补的清单：

| 项 | 现状（页面/文件所见） | 必须补 |
|---|---|---|
| 空间 | 纸本风格需要亮环境才像纸；投影在亮厅里会被洗白 | 定一个：要么暗厅 + 暗调风格（投影），要么亮厅 + 触摸大屏（纸本）。两者不能兼得 |
| 开机画面 | `?preset=kiosk` 开到点云场景 + 可见校准红线（`12-kiosk.png`）；我这次实测模式停在"指针"而非"自动展卷"（原因未核实） | 开机 URL 固定为山水场景、`grid=0`、确认自动展卷真的起来 |
| 输入 | 首页是 42 张卡片的菜单（`01-landing.png`），且标语重复出现两行、卡片布局在 1600×900 下与"展开画卷"按钮重叠 | 展厅只留 **一种** 输入；菜单页不能面向观众 |
| 声场 | README 只有一个"氛围音"生成 pad；ART-SURVEY §4.2 自承无空间化 | 至少一对音箱 + 光圈位置驱动声像；或者明确做静默作品（那就把麦克风关掉） |
| 灯光 | Art-Net/DMX 桥（文档有，未核实实物） | 若用真灯跟光，需要一盏可控射灯与控台调试半天；否则删掉这个承诺 |
| 权限与 HTTPS | 摄像头/麦克风/陀螺仪要求 HTTPS 或 localhost（README） | 现场本机 localhost 跑；手机众光要局域网 + 二维码牌 + 值守人员 |
| 运维 | ART-SURVEY §4.2 自承没有 24h soak、无重启自愈、无运行日志 | 看门狗脚本、定时刷新、断电自启；布展前跑一整夜 |
| 展签 | 页面无作者、年份、版本、材料说明（全文搜索无署名） | 展签必须写：作者、年份、"场景图为 AI 生成"、"使用摄像头/麦克风，只在本机处理，不录制"（ETHICS 原话可直接用） |
| 动线 | 一个光圈 = 一个人；共处形式要两盏光 | 画出站位区（距墙 1.5–2 m）、排队线；若用共处，入口要让观众知道要找个伴 |
| 版权 | 场景图 AI 生成，MIT 许可 | 向馆方法务确认 AI 图像展出政策；准备替代图 |

一句话：进 60 ㎡ 要先砍掉 41 种输入、10 种形式、2 张场景，再补上 1 张展签和 1 晚烤机。

## 3 · 框架能否迁移：隐藏层 + 光揭示 + 形式

- **书法** —— 隐藏：一整篇碑帖拓片（白字黑底）。揭示：光经过处按笔顺显出墨迹，光走得快笔画就细（飞白）。形式：书写 + 日课（每日只开一个字）。**最适合**：书法本来就是"时间留在纸上"。
- **摄影** —— 隐藏：同一地点相隔数年的两张照片叠在一起。揭示：光圈是放大机光束，停留越久显影越深、越偏向后一张。形式：累积 + 延迟。**最适合**：暗房显影与"光落哪显哪"是同一个隐喻，README 自己已把墨线风格叫"暗房光束"。
- **音乐** —— 隐藏：一首多声部合唱（每个声部一个空间位置）。揭示：光圈落到哪个声部就只听见它，半径 = 混音宽度。形式：静默（全场安静 20 秒才换乐章）+ 共处（二重唱要两盏光）。可行，但要先有声场。
- **舞蹈** —— 隐藏：一段舞者影像。揭示：观众自己身体的动影遮罩（动影模态）处才显出舞者，不动就看不见舞。形式：延迟 8 秒（与 8 秒前的自己对舞）。可行，但光要从"圆"变成"身影"，需改契约（ART-SURVEY 已指出）。
- **诗歌** —— 隐藏：一首完整的诗。揭示：圈内字可读、圈外是墨；在一行上停留，它就"供奉"式长大并留 90 秒。形式：供奉 + 仪式。勉强可行：阅读是线性的，圆光是空间的，两者会打架。
- **版画**（取代陶瓷） —— 隐藏：四块套色版叠成的一张年画。揭示：光圈内按停留秒数逐版套印，印上去不退。形式：累积 + 驱赶（光也能把一版"刮"掉露出下一版）。适合：版画本身就是分层叠加。

**不适合的艺术形式**
- 雕塑 / 建筑：没有可藏的"平面层"，光揭示会退化成字面意义的打光设计。
- 电影 / 长篇叙事：已有自己的时间轴；光圈只是一盏阅读灯，与剪辑争夺观众注意力。
- 现场戏剧 / 行为：表演者在场无法被"墨"盖住；延迟与静默两种形式会直接破坏现场时间。

## 4 · 三条最该改的事（策展视角）

1. **先选一种光、一种形式，再谈展览。** 一件作品只能有一个输入（ART-SURVEY §3 自己总结的"一次只做一件事"）。建议：动影（身影即光）+ 延迟 8 秒。42 张卡片留给 GitHub，不留给展厅。
2. **换掉隐藏层。** 秘密必须值得揭开：委托一位水墨作者画，或用有出处的公有领域馆藏扫描（需馆方确认版权）。把熊猫拿掉。
3. **让作品有作者、有记忆。** 展签 + 印章落款（作者/日期，不是"印"字）；留痕跨场景、跨会话保留（FORMS §4 第 1 条自己已写，还没做）；上一位观众的痕迹比自己的更重要（Kabakov 那条）。

## 5 · 摘要（10 行）

1. 总分 **5 / 10**：概念清晰可展，内容与形式尚未配得上概念。
2. 最强的一点：一句话就能懂的规则——光落在哪里哪里显色，不需要展签。
3. 第二强：伦理与工程诚实（不采集、拒绝授权仍可玩、失败回落），馆方法务会喜欢。
4. 最弱的一点：隐藏层是 AI 生成图（熊猫、麻雀），揭开的秘密不值得揭。
5. 第二弱：11 种形式在状态里存在、在眼睛里不存在，截图几乎分不出来。
6. 展厅红线：kiosk 开机落在点云 + 校准线；首页标语重复、卡片与按钮重叠；无展签、无署名。
7. 位置：介于 teamLab 屏幕作品与一个工具包之间；离 Pulse Room 差"记忆"，离 Rain Room 差"不服从"。
8. 最适合迁移的两种艺术形式：**摄影**（暗房显影同构）、**书法**（笔顺 + 日课同构）。
9. 不适合：雕塑/建筑、电影/长叙事、现场戏剧。
10. 明天进场前必做：一种输入、一张展签、一晚烤机、换掉开机场景。
