# 墨卷 · Ink Scroll — 教育 / 无障碍 / 伦理 / 多元观众 评审

评审身份：公共艺术教育与无障碍设计（美术馆教育部 + 中小学互动项目）。实测环境：Playwright Chromium 1217，`reducedMotion:'reduce'`，1440×900 与 390×844(touch, dpr3)，纯键盘。脚本 `shots/a11y-probe.js`，截图 `shots/a11y-*.png`。文中行号均指 `ink_scroll/web/index.html`。未实测的一律标「未核实」。

## 1 · 无障碍实测（WCAG 2.1 AA）

**键盘走通的路径**：Tab 到「键盘·无鼠标」卡 → Enter → Tab 到「展开画卷」→ Enter → 方向键移光（S.keys.x 实测位移）→ `PageDown` 换场景 → `M` 换模态 → `?` 开帮助 → `Esc` 关闭，焦点回到 `#b-help` → `Q` 退出。核心流程**能走通**，但有四处卡点：

1. 选完卡片后焦点丢失：`wM()` 调 `rebuildModeCards()`（:5203 → :5677 `innerHTML=''`），`document.activeElement` 变成 body；实测从「键盘」卡到「展开画卷」要再按 **47 次 Tab**（首页共 52 个可聚焦元素，没有 skip link）。
2. 开卷 (`start()`) 和退出 (`stop()`) 后焦点都落在 body，读屏用户不知道自己在哪。
3. 首页 42 张模态卡有 **22 张永远不可见**（:236 `opacity:0`，:251-256 只给 nth-child(1..6) 写了 fade-up；`.unsupported` 的 opacity:.62 例外）。reduce 与 no-preference 两种 context 都是 total 42 / visible 20（`shots/a11y-start-normal.png`）。凝视、吐纳、语音、拍手、倾斜、在场等全在看不见的那 22 张里，但仍可被 Tab 聚焦 → 焦点落在看不见的按钮上。
4. 运行中 7 个场景缩略图按钮在 `.scene-nav` opacity:0 后仍可聚焦（实测前 7 个 Tab 停在不可见元素）；`M` 循环会直接进入摄像头模态并弹权限（:5594 不过滤 needCam）。

## 2 · 伦理与数据：`docs/ETHICS.md` 的承诺 vs 代码

| 承诺 | 代码 | 判定 |
|---|---|---|
| 「没有任何上传图像的代码路径，fetch 只发 JSON」(ETHICS:32-33) | 全文只有两处 `fetch`：:3341（bridge/osc 模态下每 500 ms POST 模式/场景/bpm/presence 到本机 relay，:4775 限定）和 :4295（手机众光房间 JSON）；无 XHR/WebSocket/sendBeacon/FormData；`toDataURL` :4347 只用于本地下载 PNG。实测整场 57 个请求 0 个 POST | **一致**。注：bridge 模式下 bpm（麦克风频谱通量，:3339）和 presence 会离开标签页，虽是本机 JSON，文档应写明 |
| 「退出画面即释放摄像头轨道」(ETHICS:36) | `stop()` :5160；换到非摄像头模态 :5184-5187。实测 motion→mouse 后 `str===null`、pip 隐藏；motion→Q 后 track `readyState:'ended'` | **一致** |
| 「localStorage 只存 ink-lang」(ETHICS:35) | 还存了 `ink-onboard`（:2202/:2209）；实测 keys=[ink-onboard, ink-lang]；无 Cookie | **小不一致**，补一句即可 |
| 「心率只驱动光圈，不推断属性」(ETHICS:13-14) | :3287-3292 心率 → `B.r`（半径），别无他用；但 `acceptAllDevices:true` :3263 会列出观众附近所有 BLE 设备名 | 一致；建议收窄 filter |
| 「拒绝生理信号也必须能玩」(ETHICS:49) | ble 无设备：S.running=true，spot=null → 吸引循环自漂，HUD 显示「没有蓝牙设备 / 未授权」，`M` 一键离开（实测）；presence 无 IdleDetector 权限：ok=false 但 spot 回落指针 | **一致** |
| 「入口处明示本机处理、不录制」(ETHICS:24-25)、「16+ 或监护人」(ETHICS:28) | 页面内**没有**任何隐私或年龄文案（grep 不上传/not uploaded/16+/监护 均无）；进入摄像头模态前只提示「在镜头前动一动」:1094 | **不一致**：承诺全靠展签，软件本身不告知 |
| 「没有埋点」(ETHICS:10) | 无分析脚本；但每次打开都请求 Google Fonts（:13-15）与 jsdelivr MediaPipe（:1049-1050，非摄像头模态也加载），实测 9 个第三方 URL | 技术上无埋点，但第三方能看到访客 IP；离线课堂会掉字体 |

## 3 · 教育场景（各 45 分钟）

| 学段 | 模态 / 形式 | 学生产出 | 设备 | 流程 |
|---|---|---|---|---|
| 小学 3–5 年级「光是我的手指」 | `?mode=multi&form=offering`（多指 + 供奉：放一处痕它自己长大）；禁用摄像头/麦克风（ETHICS 16+） | 每人按 `S` 存一张「我揭开的一角」PNG + 口述一句「我看见了什么」 | 1 台触屏或平板 + 投影，无网络也行（需本地字体） | 10' 教师用 auto 模式演示「墨盖住的画」→ 25' 轮流上手，教师喊场景名换画 → 10' 看彼此 PNG 猜是哪幅 |
| 中学「身体当笔」 | `keys` / `breath` / `clap` 三选一 + `?form=delay`（8 秒回声）；先读 ETHICS.md「三条底线」 | 两张留痕截图（两种模态）+ 100 字「5 分钟后我记得什么」（FORMS.md 的提问） | 每组 1 台笔记本（内置麦克风），拒绝麦克风仍可用键盘 | 5' 授权与隐私说明 → 20' 两种模态各 10 分钟 → 10' 延迟形式 → 10' 写作 |
| 大学新媒体课「一条契约」 | 读 INTERACTIONS.md §1 `Spot{x,y,radius}` + FORMS.md §1「42 输入 × 1 形式」；用 `examples/p5_drive.html` 或 `python3 server.py` + OSC `/spot` 接一个新输入 | 一条 `M` 注册表草稿（icon/nameKey/init/spot/cln）+ 三语 I18N + 一条 test.js 断言；课后 PR | 笔记本 + Python3，可选 MIDI/手柄 | 10' 契约讲解 → 25' 结对实现 → 10' 互评「新输入改变了形式吗」 |

**现在缺的教学材料**：① 教师手册（哪些模态适合哪个年龄、禁用项）；② 课堂隐私/年龄告知模板（ETHICS:40 那段话应做成页面可开关的提示与可打印展签）；③ 离线包（CDN 字体与 MediaPipe 不可用时的降级说明）；④ 学生可读的「形式」卡片（FORMS.md 是研究文档，不是教材）；⑤ 评估量规；⑥ 场景图替换指南（CONTRIBUTING 只讲投稿，不讲「换成学生自己的画」）；⑦ 首页 22 张看不见的卡，课堂上只能靠 `M` 或 `?` 换模态。

## 4 · 多元观众（能不能玩、怎么玩）

- **轮椅使用者**：能玩。指针、键盘、`phone` 手机众光都在桌面高度；摄像头模态要把镜头调到坐姿高度（未核实实际展厅）。
- **视障**：能进、难玩。读屏能听到模式名、场景名、提示（aria-live），但「揭示」本身没有任何非视觉反馈；`A` 氛围音不随光圈位置变化（未核实）。建议：光圈位置→声像/音高，揭开面积→音量。
- **听障**：能玩。全部反馈是视觉 + 手机振动；麦克风类模态（吟诵/吹墨/拍手/语音）不适用，用键盘或指针即可；没有语音内容所以不需字幕。
- **认知障碍**：能玩 `?mode=mouse` 或 `auto`，但首页 42 张卡 + 帮助面板 59 个按钮会过载；`dwell` 停 1.4 s 就换画（:3115-3125，实测无输入也每 2.6 s 翻页）会让人以为自己弄坏了。用 `?preset=kiosk&mode=mouse` 深链。
- **老年人**：能玩 auto/mouse/multi；障碍是 8.8–11 px 小字和低对比；`dwell` 对手抖友好（26 px 阈值），需要有人把模态设好。
- **不识字儿童**：能玩 multi/mouse/auto（触屏拖动即可，图标是 SVG、场景按钮是缩略图）；入场三步 :979-983 是纯文字；摄像头与生理信号按 ETHICS 不给儿童。

## 5 · 框架迁移：「隐藏层 + 揭示 + 形式」

- **音乐**：隐藏层 = 静音的分轨；揭示 = 光圈位置解除某声部静音（Forty Part Motet，FORMS F1）；形式 = 累积（走过的声部留着）。现有 OSC `/spot` 已可直接驱动 Max/Pd，不改代码。
- **诗歌**：隐藏层 = 整页诗被墨盖住；揭示 = 光照出字；形式 = `?form=write`（笔速决定粗细）或 `?daily=1`（每天一卷）。产出就是 blackout poetry。现在用一张诗的扫描图替换 `web/scenes/` 即可开课；FORMS「字落入光圈才显影」做出来后更好。
- **舞蹈**：隐藏层 = 画；揭示 = `motion`/`multi` 多人身体；形式 = `?form=together`（一个人揭不开）+ `?delay=8000`（和 8 秒前的自己对舞）。需摄像头 → 16+ 或监护。
- **摄影**：隐藏层 = 学生自己的照片（`?video=` 或替换场景图）；揭示 = `G` 长曝 / `I` 留痕 = 快门与曝光的身体化解释；形式 = 长曝（FORMS A4）。
- **最适合课堂**：诗歌。零摄像头、零麦克风、单机投影、产出可打印、伦理风险为零；其次是摄影（用学生自己的素材）。

## 6 · 三条最该先改的

1. **把 22 张看不见的卡片显示出来**（:236 `opacity:0` 与 :251-256 只覆盖 6 张），并给隐藏态的 `.scene-nav` 加 `visibility:hidden`，别让焦点落在看不见的按钮上。
2. **焦点与播报**：`rebuildModeCards()` 后把焦点还给同一张卡；`start()`/`stop()` 后把焦点放到 `#bar` 或 `#btn-start`；`changeScene()` 调 `announce()`；首页加一个「跳到开始」链接。
3. **把伦理承诺写进界面**：进入 needCam/needMic/ble 模态前显示 ETHICS:40 那句话 + 16+ 提示（可被 `?preset=kiosk` 关闭）；ETHICS:35 补上 `ink-onboard`；字体与 MediaPipe 提供本地副本，课堂离线可用。

## 摘要

- 无障碍：**5 / 10**。骨架对（按钮语义、toolbar、dialog、live region、键盘模态、P 暂停、三语），但 22 张不可见卡、焦点丢失、换场景不播报、多处 AA 对比失败。
- 伦理一致性：**8 / 10**。不上传、不存图、释放摄像头、心率只管半径、拒绝仍能玩——代码全部兑现；扣分在「入口明示」与「16+」只在文档不在界面、localStorage 多存一项、第三方 CDN。
- 最适合的教育场景：大学新媒体课（契约文档 + 形式谱系本身就是教材）；K-12 优先用「诗歌 blackout」版本。
- 最大的一个缺口：**「揭示」没有非视觉反馈**——视障观众能进门、听到名字，却永远不知道光照亮了什么。
